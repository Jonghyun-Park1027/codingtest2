# 엑셀 활용해서 구조화 할 것

# BFS
1. start를 need_visit에 넣는다.
2. need_visit이 빌때까지(while) 앞에서부터 뽑는다.
3. 2가 visited에 없으면 넣는다.
4. 2를 방문한다.
5. 방문된 value를 need_visit에 추가한다.

# DFS
1. start를 need_visit에 넣는다.
2. need_visit을 stack구조의 pop으로 추출한다.
3. 2가 visit에 없으면 2를 넣는다.
4. 2를 방문한다.
5. 방문한 노드의 value를 need_visit에 넣는다.

# dijkstra(min heap)
1. visit(dict)에 graph의 vertices를 inf로 초기화 하여 넣고, 시작 vertex의 값을 0으로 선언한다.
2. need_visit(min heap)에 graph[start]를 넣는다. [vertex, edge]
3. need_visit이 빌때까지 뽑는다.(while)
4. 3에서 뽑힌 vertex를 원래 그래프에서 방문하고, 원소들을 순회한다(for)
5. 3과 4의 edge를 합하여 distance를 만든다.
6. visit[4.vertex]가 5보다 크면, visit에 업데이트하고, need_visit에 4의 vertex, edge를 넣는다.
